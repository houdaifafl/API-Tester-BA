# APICraft: Part 1 (single-agent development)

This branch holds the state of APICraft at the end of **Part 1** of my bachelor's thesis project at FH Aachen.

APICraft is a web application for building, organising and running API requests. The thesis compares two ways of developing it together with AI coding agents:

| Phase | Approach | Branch |
| --- | --- | --- |
| Part 1 | Single-agent development: one AI coding agent, guided by me | [`part1-single-agent-dev`](../../tree/part1-single-agent-dev) (this branch) |
| Part 2 | Multi-agent development: several specialised agents working together, coordinated by me | [`part2-multi-agent-dev`](../../tree/part2-multi-agent-dev) |

## What this branch contains

Everything on this branch was built with the single-agent approach. It is kept unchanged as the reference point for the comparison in the thesis.

The following features were implemented in Part 1:

- Authentication (login and registration)
- Workspace management
- Collection management
- Request management
- Request builder (method and URL, params and headers, body, and auth tabs)
- Request execution
- Response panel
- Sidebar search
